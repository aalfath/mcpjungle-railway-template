# Changelog

## 0.4.7 (2026-11-23)

First release of the Railway template.

- MCPJungle 0.4.7, official image `ghcr.io/mcpjungle/mcpjungle:0.4.7-stdio@sha256:4eae32ecba23e2970413a320ae1f0457f9f7dac1ee39c2b3f34f48753e918e33` (includes `npx` and `uvx`).
- Enterprise mode, initialised on first boot; admin token and a `default` MCP client token generated by Railway.
- Railway Postgres for all state; `/data` volume for STDIO server caches.
- Health check `/health`; the start script exits non-zero if the gateway stops, so Railway restarts it.
- Telemetry (`/metrics`) off by default.
